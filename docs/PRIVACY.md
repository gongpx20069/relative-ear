# 隐私说明

本文件描述当前 `0.0.4` 的数据边界；操作说明见 [README](../README.md)，技术细节见 [DEVELOPMENT](DEVELOPMENT.md)。

## 麦克风

唱唱名和识音在用户主动开始后采集声音，用于本机音高计算。练耳、单音试听、唱名示范与听答案只播放合成音，不需要麦克风权限。

应用没有后台录音服务。离开页面、应用进入后台或中断训练时停止采集；返回后需要用户重新开始。

PCM 音频仅用于内存计算，不生成录音文件、不上传、不写入诊断日志。识音曲线和最近音符序列只在当前页面内存中保留。

## 本地数据

训练数据库保存题型、基准/目标、答案、是否正确/超时、音分偏差、反应时间、重播次数、时间戳、会话 ID 和评分设置快照。新版记录还保存考核音符范围、唱名/音名显示与播放 BPM。设置保存 A4 基准、容差、八度模式及上次练习配置。

数据位于 Android 应用私有目录，无账号、无广告或分析 SDK，不请求联网权限。系统云备份关闭。

## 删除

在设置中确认“删除全部训练记录”可删除成绩，但保留设置。卸载 App 或使用系统“清除应用数据”会删除所有本地成绩和设置。

## 诊断

故障日志可能包含音频设备状态、错误码和本地数据库异常，不包含原始音频。用户自行分享系统日志之前仍应检查其中是否包含其他应用的信息。

如未来加入上传、账号、录音保存或外部模型服务，必须先更新本说明、用户提示及权限流程，不能默认扩展当前同意范围。
