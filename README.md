# Relative Ear

面向音乐爱好者的 Android 相对音感训练应用。

核心闭环：建立调性或播放基准音 → 听辨或唱回 → 本地音高检测与反馈 → 训练统计。

## 项目状态

当前处于设计阶段，尚未生成 Android 工程或实现应用功能。

- [设计文档](docs/DESIGN.md)：产品边界、交互、架构、音频算法、评分与验收计划。
- 首发平台：Android。
- 首版语言：简体中文，预留英文资源。
- 首版原则：离线优先，无账号，无云端音频处理。
